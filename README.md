# Tower Builder

3D-игра на Three.js: роняй этажи точно друг на друга и собери самую высокую башню.

- Нажми на экран или пробел, чтобы опустить этаж
- Свисающая часть отрезается
- Точное попадание добавляет стеклянный эркер, 4 подряд расширяют этаж
- 1 этаж = 3 м, рекорд сохраняется в браузере

Запуск: открой `index.html` в браузере.
